# JinxApex

JinxApex is a real-time distributed system that leverages event-driven and auto-scaling for efficient data management and controller optimization.

With JinxApex, you get a lightweight tool that stays out of your way.

**What you get**

- JinxApex is a real-time distributed
- system that leverages event-driven and
- auto-scaling for efficient data management

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/JinxApex.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

JinxApex is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
